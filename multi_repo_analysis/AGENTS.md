## What this is

Generated output of the multi-repository analysis (`python main.py` or
`opentir multi-analysis`): `reports/` holds the four markdown reports
(`executive_summary.md`, `technical_report.md`, `language_analysis.md`,
`repository_rankings.md`), `visualizations/` holds the PNG charts
(activity timeline, complexity heatmap, dependency graph, functionality network,
language distribution, repository sizes). `./run.sh` prints file:// links to
these after a successful run.
