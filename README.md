# Opentir

Opentir extracts source metadata from local repository checkouts and produces
JSON analysis and MkDocs documentation. It uses Python's abstract syntax
tree for Python source and pattern-based extraction for some other languages.

Start at the [documentation index](docs/README.md). The [local walkthrough](docs/local-analysis.md)
uses a small inventory example and demonstrates offline analysis and report
generation. The [technical note](docs/manuscript/README.md) records the observed
output and its scope.
