> Repository-wide policy for template projects is maintained in the template repository, not restated here.

## What this is

Markdown templates consumed by `src/docs_generator.py` when rendering the
generated documentation site: `main_index.md` (index page),
`repository_detail.md` (per-repo page), `functionality_matrix.md` (function
catalog table). `__init__.py` makes the directory importable.

```
__init__.py, functionality_matrix.md, main_index.md, repository_detail.md
```
